# 网络工程师 · 刷题（软考中级）

2026 下半年软考 **网络工程师（中级）** 考前冲刺用的纯静态刷题站，手机浏览器打开即用，无需安装、无需登录。

## 打开

https://xzyonline.github.io/ne-quiz/

建议在手机浏览器里「添加到主屏幕」，下次一点就进。

## 内容

| 模块 | 数量 |
| --- | --- |
| 选择题总库 | 780 道（含 36 道带图题） |
| 历年真题 | 2 套（2026 上 / 2025 下 · 考生回忆版） |
| 冲刺模拟 | 2 套（各 75 题 / 120 分钟计时） |
| 考前密押 | 1 套（75 题，按公开高频考点自编，非泄题） |
| 下午案例 | 2 卷 8 大题 32 小问 / 150 分 |
| 记忆卡 | 60 张 |

按 18 个专题分组：数据通信、体系结构、局域网与交换、IP 与子网、路由、传输层与应用、无线、网络安全、存储与 RAID、规划与布线、网络管理、法规与标准、Linux 与命令、华为配置、术语英语、新技术等。

## 功能

- 逐题作答（选项自动打乱，避免位置记忆）、错题本、收藏
- 真题 / 冲刺 / 密押整卷模考，倒计时到点自动交卷
- 下午案例支持填空、选择自动判分，简答题三级自评（完整 / 部分 / 未答）
- 案例「看答案」模式 + 独立答案速查页，不交卷也能先背
- 学习报告：总体正确率、连续学习天数、18 专题掌握度
- 进度导出 / 导入（换网址、换手机时搬记录）

## 说明

- 数据全部存在浏览器 `localStorage`（键 `ne_quiz_v2`），不上传任何服务器。
- 真题为考生回忆版整理，题面与原卷可能有差异；密押卷为按公开高频考点自编，**不是官方试题、不是泄题**，只用于查漏补缺。
- 站点为纯静态单页，`index.html` + 若干 `window.*` 数据脚本，无框架、无构建、无后端。
